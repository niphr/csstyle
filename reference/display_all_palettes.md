# Display all available color palettes

Creates a visualization showing all available CSIDS color palettes with
their color codes and names.

## Usage

``` r
display_all_palettes()
```

## Value

A ggplot2 plot displaying all color palettes

[`set_global()`](https://niphr.github.io/csstyle/reference/set_global.md)
